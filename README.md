# DumbestBOT/.github

Organization-level files for the [DumbestBOT](https://github.com/DumbestBOT) org:

- `profile/README.md` — the public [org profile page](https://github.com/DumbestBOT)
- `banner.png`, `avatar.png` — brand assets (pixel-terminal robot, generated by [`scripts/gen-branding.mjs`](https://github.com/Shimba-crypto/DumbCode/blob/main/scripts/gen-branding.mjs) in DumbCode)

**DumbestBOT** is a GitHub App powered by [DumbCode](https://github.com/Shimba-crypto/DumbCode), the open-source zero-dependency agent CLI: mention `@dumbestbot` on an issue or PR in an installed repo and it investigates with real agent tools. Install: **https://github.com/apps/dumbestbot**
